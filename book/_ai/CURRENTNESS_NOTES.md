# Currentness notes for writers and reviewers

These are specific inspected-source findings, not a replacement for checking each chapter's actual tool baseline. Checked 2026-10-01.

- Kubernetes Ingress NGINX: the Kubernetes committees [announced retirement for March 2026](https://kubernetes.io/blog/2026/01/29/ingress-nginx-statement/). Do not teach installing community `ingress-nginx` as a maintained new-production default. Discuss migration and choose a currently supported controller/Gateway implementation after verifying its documentation. This retirement is distinct from Nginx itself and other vendors' similarly named controllers.
- Podman networking: [current project networking documentation](https://github.com/podman-container-tools/podman/blob/main/docs/tutorials/basic_networking.md) and [performance documentation](https://github.com/podman-container-tools/podman/blob/main/docs/tutorials/performance.md) describe pasta for rootless operation; current main documents state it is the only rootless driver since Podman 6.0. Older packaged Podman can differ. Do not present slirp4netns-era defaults as universal current behavior.
- Jenkins installation: the [official Linux installation instructions](https://www.jenkins.io/doc/book/installing/linux/) currently describe Java 21 installation and a 2026 repository signing key. Verify both supported Java versions and the exact current repository instructions; do not paste old key URLs from memory.
- Loki collection: [Promtail reached end of life on March 2, 2026](https://grafana.com/docs/alloy/latest/set-up/migrate/from-promtail/), and [Grafana Agent reached end of life on November 1, 2025](https://grafana.com/docs/agent/latest/about/). Teach a maintained collector such as Grafana Alloy or a verified OpenTelemetry integration, and discuss the older tools only as migration context.
- Terraform S3 state locking: the [specific S3 backend reference](https://developer.hashicorp.com/terraform/language/backend/s3) marks DynamoDB locking deprecated and documents `use_lockfile`. Verify the installed Terraform/OpenTofu version and respective backend semantics; do not assume they support identical options. S3 lock files require their own scoped permissions.

Describe deprecated tooling as historical or migration context, with dates. A familiar tutorial can be obsolete even when its commands still appear in search results.
